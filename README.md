# JPComedy 共用漫才詞庫

這裡保存日本漫才、藝人組合、節目和術語的固定繁中譯名，供 [JPComedy 翻譯工具](https://github.com/allen365apple/owarai-grillmaster) 使用。

[開啟詞庫網頁](https://allen365apple.github.io/owarai-grillmaster/) · [提出譯名建議](https://github.com/allen365apple/jpcomedy-glossary/issues/new)

目前網站支援瀏覽、搜尋、編輯草稿與匯出。指定 GitHub 帳號登入保存，待管理員完成 GitHub App／後端設定後開放；頁面會標示實際狀態。在此之前，請將草稿交給「看我笑話工作室」柏文整合，或使用 Issues 提供建議。

提出建議時請寫日文原名、建議繁中譯名，以及可參考的來源。不確定的名稱可以先討論；暫時不用的詞使用 `disabled: true` 封存。

資料格式在 `glossary.json`；每次更新保留 Git 歷史。新影片會檢查更新，已開始的影片保留自己的快照。原始詞庫來源為 [elishahung/owarai-grillmaster](https://github.com/elishahung/owarai-grillmaster) 及其衍生 JPComedy 版本；保留原作者貢獻，不另行宣稱新的授權條款。

維護者可用 GitHub 網頁編輯 `glossary.json`，但請確認 JSON 格式正確。線上編輯器啟用後，GitHub login 和數字帳號 ID 會記錄於公開 commit，便於追溯與協作。
